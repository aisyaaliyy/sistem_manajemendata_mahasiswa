# Student Management - React UI Implementation Practice

Sistem Student Management dengan ReactJS untuk menampilkan data mahasiswa.

## Fitur
- `useState` untuk menyimpan data mahasiswa dummy tanpa melibatkan backend dan waktu terkini
- `useEffect` + `setInterval` + `clearInterval` untuk jam digital
- `.map()` untuk looping data mahasiswa ke baris tabel (key unik: `student.id`)
- Fitur tambahan: pencarian (nama/NIM), filter program studi, pagination
